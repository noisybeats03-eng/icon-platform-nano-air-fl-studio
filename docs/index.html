Instálalo en FL StudioInstall it in FL Studio

Son unos minutos y no necesitas saber programar. Si quieres más detalle, sigue el manual de instalación en GitHub.

It takes a few minutes and you don't need to know how to program. For more detail, follow the installation manual on GitHub.

En esta guía, los nombres de los menús y botones de FL están en inglés. Si tu FL está en otro idioma, se ven traducidos. La tecla F10 abre MIDI settings en cualquier idioma.

In this guide, FL's menus and buttons are named as FL shows them in English. If your FL is set to another language, they appear translated. The F10 key opens MIDI settings in any language.

  1. Descarga el script. Baja iCON-Platform-Nano-Air-FL-Studio-v1.1.0.zip de la página de descargas y descomprímelo (clic derecho → Extraer todo). Trae dos cosas: la carpeta del script y este mismo tutorial (en español e inglés), Tutorial iCON Platform Nano Air FL Studio (ES-EN).html, que se abre con doble clic aunque no tengas internet.
  2. Copia la carpeta. Copia la carpeta iCON Platform Nano Air FL Studio (con el archivo device_iCON_PlatformNanoAir_FLStudio.py adentro) en Documentos\Image-Line\FL Studio\Settings\Hardware. Si FL usa otra carpeta de datos, la ves en Options → File settings (User data folder): entra ahí a FL Studio\Settings\Hardware. En Mac: ~/Documents/Image-Line/FL Studio/Settings/Hardware (no se ha probado en Mac).
  3. Pon el Nano en modo MCP (Mackie Control). Al prenderlo (el switch está atrás: es el del extremo izquierdo si miras la parte de atrás), la pantalla pide el modo unos segundos: elige MCP con los botones de colores 1 y 2 de la fila de arriba (« y ») y confirma con el 3 (DAW Mode). El Nano lo recuerda. Inalámbrico: conecta antes el receptor USB de iCON a la compu; cuando se enlazan, la pantalla dice Paired.
  4. Reinicia FL Studio (ciérralo y vuelve a abrirlo, ya con el Nano prendido en modo MCP).
  5. Configura la entrada. Options → MIDI settings (F10). En la lista Input elige el Nano (por ejemplo «PlatformNano Air V1.02» inalámbrico o «PlatformNano(A) V2.05» por cable), en Controller type elige iCON Platform Nano Air (custom) y pon Port 1. Ojo: al elegir el Controller type, Enable se prende solo; si le das clic, se apaga (fíjate en su luz).
  6. Configura la salida. En la lista Output elige el mismo Nano y ponle el mismo Port (1). Cierra la ventana.
  7. Comprueba. En View → Script output, la pestaña del Nano dice OnInit ready. La pantalla del Nano muestra FL LISTO unos 2 segundos y luego el canal seleccionado y su volumen, por ejemplo Vocal -5.2dB . Toca el fader una vez: así el script aprende en qué lugar del banco está el fader.
  1. Download the script. Get iCON-Platform-Nano-Air-FL-Studio-v1.1.0.zip from the downloads page and unzip it (right-click → Extract All). It contains two things: the script folder and this same tutorial (in Spanish and English), Tutorial iCON Platform Nano Air FL Studio (ES-EN).html, which opens with a double-click even without internet.
  2. Copy the folder. Copy the iCON Platform Nano Air FL Studio folder (with the file device_iCON_PlatformNanoAir_FLStudio.py inside) into Documents\Image-Line\FL Studio\Settings\Hardware. If FL uses another data folder, you can see it in Options → File settings (User data folder): go into FL Studio\Settings\Hardware there. On a Mac: ~/Documents/Image-Line/FL Studio/Settings/Hardware (not tested on Mac).
  3. Put the Nano in MCP mode (Mackie Control). When you switch it on (the power switch is on the back: it's the one at the far left when you look at the back panel), the screen asks for the mode for a few seconds: choose MCP with colored keys 1 and 2 of the top row (« and ») and confirm with key 3 (DAW Mode). The Nano remembers it. Wireless: first plug iCON's USB receiver into the computer; when they pair, the screen says Paired.
  4. Restart FL Studio (close it and open it again, with the Nano already on in MCP mode).
  5. Set up the input. Options → MIDI settings (F10). In the Input list, pick the Nano (for example "PlatformNano Air V1.02" wireless or "PlatformNano(A) V2.05" by cable), in Controller type choose iCON Platform Nano Air (custom) and set Port 1. Careful: choosing the Controller type already turns Enable on; if you click it, it turns off (watch its light).
  6. Set up the output. In the Output list, pick the same Nano and give it the same Port (1). Close the window.
  7. Check. In View → Script output, the Nano's tab says OnInit ready. The Nano's screen shows FL LISTO ("ready") for about 2 seconds, then the selected track and its volume, for example Vocal -5.2dB . Touch the fader once: that's how the script learns where the fader is in the bank.

¿Usas el cable y también el receptor inalámbrico? FL los ve con dos nombres y guarda cada uno por separado: haz los pasos 5 y 6 con los dos (si no, el día que se acabe la batería y conectes el cable parecerá que se borró todo). Para volver al script original de FL, elige Controller type «Mackie Control Universal»; para desinstalar, elige otro Controller type y borra la carpeta.

Do you use the cable and also the wireless receiver? FL sees them under two names and keeps the settings of each one separately: do steps 5 and 6 for both (otherwise, the day the battery runs out and you plug in the cable, it will look as if everything was erased). To go back to FL's original script, choose Controller type "Mackie Control Universal"; to uninstall, choose another Controller type and delete the folder.

Lo que hacen otros controladores, hecho en esteWhat other controllers do, done on this one

Mezclar canal por canal

  1. Toca Mixer (capa verde, botón 2).
  2. Gira la rueda hasta el canal; el fader se va a su volumen y la pantalla dice su nombre.
  3. Ajusta con el fader; usa Mute, Solo y Rec para ese canal.
  4. Toca Mixer otra vez para que la rueda vuelva a lo normal.

Mix track by track

  1. Press Mixer (green layer, key 2).
  2. Turn the wheel to the track; the fader moves to its volume and the screen shows its name.
  3. Adjust with the fader; use Mute, Solo and Rec for that track.
  4. Press Mixer again so the wheel goes back to normal.

Grabar automatización con el fader

  1. En FL elige el pattern donde se guardará: FL guarda los movimientos dentro del pattern seleccionado.
  2. Clic derecho en el botón de grabar de FL y marca "Automation" (quita "Audio" y "Notes" si solo quieres el movimiento).
  3. Elige el canal con Mixer + rueda.
  4. Toca ● y luego ▶ en el Nano y mueve el fader o las perillas mientras suena.
  5. ■ para terminar. Para verlo: clic derecho en el control de FL → Edit events; desde ahí puedes convertirlo en clip (Turn into automation clip).
  6. Pruébalo una vez antes de confiar en él: FL no documenta cómo graba los movimientos que llegan de un script Mackie.

Record automation with the fader

  1. In FL, choose the pattern where it will be saved: FL stores the movements inside the selected pattern.
  2. Right-click FL's record button and check "Automation" (uncheck "Audio" and "Notes" if you only want the movement).
  3. Choose the track with Mixer + wheel.
  4. Press ● and then ▶ on the Nano, and move the fader or the knobs while it plays.
  5. ■ to finish. To see it: right-click the control in FL → Edit events; from there you can turn it into a clip (Turn into automation clip).
  6. Try it once before you rely on it: FL doesn't document how it records the movements that come from a Mackie script.

Controlar la perilla de un plugin

  1. Toca Free en la columna derecha, para que la perilla del Nano no esté haciendo otra cosa.
  2. En FL, clic derecho en la perilla del plugin → Link to controller….
  3. Mueve la perilla o el fader del Nano: "Auto Detect" llena los datos solo. Luego Accept.
  4. Varios a la vez: prende Multilink (Ctrl+J), mueve las perillas de FL y luego las del Nano en el mismo orden.
  5. Para cambiar un enlace, vuelve a ligarlo con "Remove Conflicts" marcado; la lista está en Browser → Current project → Remote control.

Control a plugin knob

  1. Press Free in the right-hand column, so the Nano's knob isn't doing something else.
  2. In FL, right-click the plugin knob → Link to controller….
  3. Move the Nano's knob or fader: "Auto Detect" fills in the details by itself. Then Accept.
  4. Several at once: turn on Multilink (Ctrl+J), move the FL knobs and then the Nano's in the same order.
  5. To change a link, link it again with "Remove Conflicts" checked; the list is in Browser → Current project → Remote control.

Grabar la voz en loop

  1. Selecciona la parte: Ctrl + arrastrar en la regla de compases de la Playlist.
  2. Prende Loop (⟲) y, si quieres, 3..2..1 (capa azul, 6).
  3. Arma un canal del Mixer: al elegir la entrada de tu micro se arma solo (o usa Rec en el Nano).
  4. ● y ▶: FL repite la parte y deja una toma por vuelta en la Playlist; ■ para terminar.
  5. Para que cada toma quede limpia, FL recomienda grabar en un canal normal del Mixer y no en un Audio Track.

Record vocals in a loop

  1. Select the part: Ctrl + drag on the Playlist's bar ruler.
  2. Turn on Loop (⟲) and, if you like, 3..2..1 (blue layer, 6).
  3. Arm a mixer track: choosing your mic's input arms it by itself (or use Rec on the Nano).
  4. ● and ▶: FL repeats the part and leaves one take per pass in the Playlist; ■ to finish.
  5. To keep each take clean, FL recommends recording on a normal mixer track, not on an Audio Track.

Grabar solo una parte

  1. Clic derecho en el botón de grabar de FL y marca "Enable recording markers".
  2. Selecciona la parte (Ctrl + arrastrar en la regla) y usa menú Playlist → Time markers → "Start recording/Stop recording at selection".
  3. Consejo: quita la selección (Ctrl+D), arma el canal y da ▶ unos compases antes; FL empieza y deja de grabar solo en esos marcadores.

Record only one part

  1. Right-click FL's record button and check "Enable recording markers".
  2. Select the part (Ctrl + drag on the ruler) and use the Playlist menu → Time markers → "Start recording/Stop recording at selection".
  3. Tip: clear the selection (Ctrl+D), arm the track and press ▶ a few bars earlier; FL starts and stops recording by itself at those markers.

Grabar con Edison

  1. Selecciona un canal del Mixer con la entrada de tu micro.
  2. Toca Edison (capa azul, 3) para abrirlo en ese canal.
  3. Si quieres que grabe en cuanto das Play, en FL usa Shift+E en ese canal: Edison queda listo con "On play".
  4. ▶ para grabar, ■ para parar; Shift+C manda la toma a la Playlist.

Record with Edison

  1. Select a mixer track that has your mic's input.
  2. Press Edison (blue layer, 3) to open it on that track.
  3. If you want it to record as soon as you press Play, use Shift+E on that track in FL: Edison is ready with "On play".
  4. ▶ to record, ■ to stop; Shift+C sends the take to the Playlist.

Moverte por la canción

  1. Con la Playlist enfocada, la rueda sin modo mueve la posición; « y » retroceden y adelantan.
  2. +Mark (capa morada, 8) deja marcadores; Mark (morada, 7) + rueda salta entre ellos.
  3. Zoom ↕ / Zoom ↔ + rueda para acercar.

Move around the song

  1. With the Playlist focused, the wheel with no mode moves the position; « and » rewind and fast-forward.
  2. +Mark (purple layer, 8) adds markers; Mark (purple, 7) + wheel jumps between them.
  3. Zoom ↕ / Zoom ↔ + wheel to zoom in.

Editar rápido

  1. Capa amarilla: Cut, Copy, Paste, Insert y Del, sobre la ventana activa. Ojo en la Playlist: Insert corta el clip y Del lo borra.
  2. Undo (amarilla, 7): un toque deshace un paso; Un/Redo (8) alterna deshacer y rehacer.
  3. Save (capa morada, 1) guarda; con Shift, una versión nueva.

Quick editing

  1. Yellow layer: Cut, Copy, Paste, Insert and Del, on the focused window. Careful in the Playlist: Insert splits the clip and Del deletes it.
  2. Undo (yellow, 7): one tap undoes one step; Un/Redo (8) toggles between undo and redo.
  3. Save (purple layer, 1) saves; with Shift, a new version.

Qué cambia este script respecto al de FL StudioWhat this script changes compared with FL Studio's

El script iCON Platform Nano Air (custom) es una copia del script Mackie Control Universal que trae FL Studio (versión 2026.1, de Image-Line) con estos cambios. Los 40 botones de colores ya mandaban exactamente lo que dice el overlay de FL de iCON; lo que cambia es cómo responden.

The iCON Platform Nano Air (custom) script is a copy of the Mackie Control Universal script that comes with FL Studio (version 2026.1, by Image-Line) with these changes. The 40 colored-key functions already sent exactly what iCON's FL overlay says; what changes is how they respond.

El fader sigue al canal seleccionado

En el script de FL el fader quedaba fijo en un canal del banco; ahora va al canal que elijas (con Mixer + rueda, |< >| o el mouse), y Mute, Solo, Rec y la pantalla también.

The fader follows the selected track

With FL's script, the fader stayed on one fixed track of the bank; now it goes to the track you choose (with Mixer + wheel, |< >| or the mouse), and so do Mute, Solo, Rec and the screen.

Modos de la rueda con un toque

En FL había que mantenerlos apretados. Ahora un toque los deja prendidos y otro los apaga; mantener + girar sigue funcionando.

One-tap wheel modes

With FL's script you had to keep them held. Now one tap turns them on and another tap turns them off; hold + turn still works.

Zoom en dos ejes

Zoom ↕ cambia la altura de los tracks y Zoom ↔ el zoom horizontal, como dice iCON. En FL ambos hacían zoom horizontal.

Zoom on both axes

Zoom ↕ changes the track height and Zoom ↔ the horizontal zoom, as iCON's labels say. With FL's script, both did horizontal zoom.

Undo de un toque

La tecla amarilla 7 dice Undo pero en FL solo recorría el historial; ahora un toque deshace un paso.

One-tap Undo

Yellow key 7 says Undo, but with FL's script it only walked through the history; now one tap undoes one step.

Loop de verdad

El botón ⟲ en FL prendía el Snap; ahora prende la grabación en loop, y Shift + Loop prende el Snap.

A real Loop

With FL's script, the ⟲ key turned on Snap; now it turns on loop recording, and Shift + Loop turns on Snap.

Pantalla clara

El script de FL está hecho para la pantalla larga de una consola Mackie: en el Nano salían rayitas y textos cortados, y al mover el fader brincaba entre dos mensajes. Ahora arriba sale el canal y abajo su volumen real en dB; los mensajes son cortos, completos y duran 1.5 s; al mover el fader solo cambia el número, y en modo Tempo el reloj de dígitos muestra el BPM. En la pantalla externa cada cuadro muestra un canal del banco y su paneo, y el cuadro del fader, el canal seleccionado.

A readable screen

FL's script is made for the long display of a Mackie console: on the Nano it showed dashes and cut-off texts, and moving the fader made it jump between two messages. Now the top line shows the track and the bottom line its real volume in dB; messages are short, whole and last 1.5 s; when you move the fader only the number changes, and in Tempo mode the digit display shows the BPM. On the external display, each square shows a track of the bank and its pan, and the fader's square shows the selected track.

Fader más estable

Si dejas el dedo quieto sobre el fader, sus pequeños temblores ya no mueven el volumen. Si cambias de canal mientras lo tocas, el canal nuevo no cambia hasta que el fader llega a su nivel o lo sueltas.

A steadier fader

If you rest your finger on the fader, its tiny tremors no longer move the volume. If you change track while you touch it, the new track isn't changed until the fader reaches its level or you let go.

Errores del script de FL Studio corregidos

Shift + Solo ya no da error; mantener Undo y girar la rueda ya funciona; Shift + amarilla 7 (F7) ya no deshace un paso si sueltas Shift primero; y en la página Free la pantalla muestra bien el valor del fader.

Fixed bugs from FL Studio's script

Shift + Solo no longer gives an error; holding Undo and turning the wheel now works; Shift + yellow 7 (F7) no longer undoes a step if you let go of Shift first; and on the Free page the screen shows the fader value correctly.

Los 40 botones de colores, la columna derecha y el transporte ya coincidían con el overlay oficial de FL; no se tocaron.

Everything else, as iCON made it

The 40 colored-key functions, the right-hand column and the transport already matched the official FL overlay; they were left untouched.

Si algo no funcionaTroubleshooting

No sale "iCON Platform Nano Air (custom)" en Controller type

La carpeta "iCON Platform Nano Air FL Studio", con el archivo device_iCON_PlatformNanoAir_FLStudio.py adentro, debe quedar en Documentos\Image-Line\FL Studio\Settings\Hardware (o en FL Studio\Settings\Hardware dentro de la carpeta de datos que dice Options → File settings → User data folder). Revisa que al descomprimir no haya quedado una carpeta dentro de otra y reinicia FL.

"iCON Platform Nano Air (custom)" is not in Controller type

The "iCON Platform Nano Air FL Studio" folder, with the file device_iCON_PlatformNanoAir_FLStudio.py inside, must end up in Documents\Image-Line\FL Studio\Settings\Hardware (or in FL Studio\Settings\Hardware inside the data folder shown in Options → File settings → User data folder). Check that unzipping didn't leave one folder inside another, and restart FL.

El Nano no aparece en MIDI settings

Revisa que esté prendido. Inalámbrico: el receptor USB de iCON debe estar conectado y la pantalla del Nano debe decir Paired; si no se enlaza, usa el cable USB. Luego, en Options → MIDI settings, haz clic en Refresh device list (o reinicia FL).

The Nano doesn't appear in MIDI settings

Check that it's switched on. Wireless: iCON's USB receiver must be plugged in and the Nano's screen must say Paired; if they don't pair, use the USB cable. Then, in Options → MIDI settings, click Refresh device list (or restart FL).

FL Studio no hace caso al controlador

En FL: Options → MIDI settings (F10). En Input, el Nano debe tener Controller type "iCON Platform Nano Air (custom)", Port 1 y Enable prendido: al elegir el Controller type, Enable se prende solo, y si después le das clic se apaga. En Output, el mismo Nano con el mismo Port 1 (sirve otro número libre, pero el mismo en los dos).

FL Studio ignores the controller

In FL: Options → MIDI settings (F10). In Input, the Nano must have Controller type "iCON Platform Nano Air (custom)", Port 1 and Enable on: choosing the Controller type already turns Enable on, and if you click it afterwards it turns off. In Output, the same Nano with the same Port 1 (another free number works too, but it must be the same in both).

Parece que se borró la configuración

Pasa al cambiar de inalámbrico a cable o al revés: FL ve otro nombre ("PlatformNano Air V1.02" inalámbrico, "PlatformNano(A) V2.05" por cable; con otro firmware pueden ser otros) y guarda la configuración de cada nombre por separado. Configura el otro nombre una vez, igual que el primero, y ya queda.

The setup seems to be gone

It happens when you switch from wireless to cable or the other way around: FL sees another name ("PlatformNano Air V1.02" wireless, "PlatformNano(A) V2.05" by cable; with other firmware they may be different) and keeps the settings of each name separately. Set up the other name once, the same way as the first one, and that's it.

La pantalla del Nano no prende

El switch de encendido está atrás: es el del extremo izquierdo si miras la parte de atrás (– prendido, O apagado). También se carga por el USB mini. Si se acabó la batería, conéctalo por cable: funciona igual, aunque FL lo ve con otro nombre (ver "Parece que se borró la configuración").

The Nano's screen doesn't light up

The power switch is on the back: it's the one at the far left when you look at the back panel (– on, O off). It also charges through the mini USB port. If the battery is empty, connect it by cable: it works the same, although FL sees it under another name (see "The setup seems to be gone").

Los botones hacen cosas raras

Revisa que el Nano esté en modo MCP: al encenderlo, la pantalla pide el modo unos segundos; elige MCP con los botones de colores 1 y 2 de la fila de arriba (« y ») y confirma con el 3 (DAW Mode). Lo recuerda para la próxima.

The keys do strange things

Check that the Nano is in MCP mode: when you switch it on, the screen asks for the mode for a few seconds; choose MCP with colored keys 1 and 2 of the top row (« and ») and confirm with key 3 (DAW Mode). It remembers it for next time.

El fader no se mueve

Revisa que no esté prendido Flip (capa roja, 1) ni Master, y que estés en Pan, Stereo, Sends o Effects.

The fader doesn't move

Check that neither Flip (red layer, 1) nor Master is on, and that you are on Pan, Stereo, Sends or Effects.

Un botón hizo algo inesperado

Casi todo depende de la ventana enfocada en FL. Mira el mensaje arriba a la izquierda de FL: dice qué acaba de pasar. Si fue un error, Undo (amarilla, 7).

A key did something unexpected

Almost everything depends on FL's focused window. Look at the message at FL's top left: it says what just happened. If it was a mistake, Undo (yellow, 7).

Quiero el comportamiento original de FL Studio

En MIDI settings cambia Controller type a "Mackie Control Universal". Para volver, elige otra vez "iCON Platform Nano Air (custom)". Para desinstalarlo, elige otro Controller type y borra la carpeta "iCON Platform Nano Air FL Studio".

I want FL Studio's original behavior

In MIDI settings, change Controller type to "Mackie Control Universal". To come back, choose "iCON Platform Nano Air (custom)" again. To uninstall it, choose another Controller type and delete the "iCON Platform Nano Air FL Studio" folder.

Ver errores del script

En FL: View → Script output, en la pestaña con el nombre del Nano (PlatformNano Air o PlatformNano(A)). Debe decir "OnInit ready". El aviso "Invalid mixer track nr 501" viene del script original de FL y no afecta.

See the script's errors

In FL: View → Script output, on the tab with the Nano's name (PlatformNano Air or PlatformNano(A)). It must say "OnInit ready". The warning "Invalid mixer track nr 501" comes from FL's original script and is harmless.

La pantalla muestra nombres de menús

Si abres menús de FL con el mouse, FL manda el nombre del menú a la pantalla del Nano (por ejemplo Menu y View). Es normal y se quita solo.

The screen shows menu names

If you open FL's menus with the mouse, FL sends the menu name to the Nano's screen (for example Menu and View). That's normal and goes away by itself.

La pantalla externa repite lo mismo en los 8 cuadros

Pasa al cargar el script. Toca el fader una vez: el script aprende en qué cuadro está y cada cuadro pasa a mostrar su canal.

The external display shows the same thing on all 8 squares

It happens when the script loads. Touch the fader once: the script learns which square it is on and each square starts showing its own track.
